# Marco Olivari Website

Static GitHub Pages website for:

```text
https://marcoolivari.github.io
```

## Update

- Edit the main page in `index.html`.
- Edit the design in `styles.css`.
- Put your CV at `assets/cv.pdf`.
- Replace the placeholder portrait with `assets/portrait.jpg`, then update the image path in `index.html`.
- Put papers in `papers/`.
- Put slides in `slides/`.

## Publish

Commit and push to GitHub:

```bash
git add .
git commit -m "Create academic website"
git push
```

Then enable GitHub Pages under `Settings -> Pages` using branch `main` and folder `/root`.
